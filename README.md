Задача 3:
docker attach подключает терминал напрямую к основному процессу контейнера (PID 1).В нашем случае это nginx. Нажатие Ctrl-C посылает сигнал SIGINT именно nginx, nginx его получает и завершается.Как только PID 1 умирает — контейнер останавливается.Это отличается от docker exec, который запускает новый процесс внутри контейнера и не трогает основной.
